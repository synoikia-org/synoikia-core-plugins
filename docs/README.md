# Docs

- [`adrs/`](adrs/): the security decisions of the plugins. ADR-0001 holds the rules that every plugin follows, and each other ADR covers one plugin or one family. Synoikia core's [ADRs](https://github.com/synoikia-org/synoikia-core/tree/main/docs/adrs) apply to everything else: access levels, approvals, redaction and the admin portal. If an ADR here and a core ADR do not agree, the core ADR applies.
- [`mockups/homeassistant-match-selector`](mockups/homeassistant-match-selector): the chosen design for the Home Assistant target picker on the Pre-Approval Rules form. The `.dc.html` files are Claude Design Component sources. Read the markup as a spec, or paste one into a new Claude Design artifact to render it.
